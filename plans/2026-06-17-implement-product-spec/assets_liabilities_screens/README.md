# Assets & Liabilities Screens — Updated

These mock screens reflect the revised account/entity semantics:

- top-level metric strip appears directly below the page title
- overview rows are grouped by account/entity type; type is implied by grouping
- source-of-truth is not shown as an overview table column
- Add item modal uses clearer onboarding language: "Need to bring in Aspire data? Use Onboarding."
- account detail pages share consistent chrome:
  - header with back link, title, badges, and right-aligned actions
  - metric strip directly beneath the header
  - wide primary activity table plus narrower right rail
  - charts consistently placed in the lower content section
  - large centered modals for contribution, payment, and upgrade/cutover flows
- investment contribution semantics show two-leg account transfers plus derived budget effects from linked category behavior
- loan payment flow uses the same centered modal pattern as other flows

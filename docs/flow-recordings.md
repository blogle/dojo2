# Dojo Flow Recordings

These presentation specs use the deterministic E2E harness. Generate all flows
with `just record-flows`, or one flow with `just record-flow <flow>`. Artifacts
are written outside the repository under
`${XDG_CACHE_HOME:-$HOME/.cache}/dojo/e2e/recordings/`.

Run `just storyboard` to run all recording specs and copy only the six final
storyboard PNGs into the tracked `storyboards/` directory for demos. MP4s,
checkpoint screenshots, and manifests remain in the external recording
directory.

| Recording | Demonstrates | Source spec | Regeneration |
| --- | --- | --- | --- |
| `01-onboarding-start-empty` | Start empty from a clean onboarding state through the required backup setup | `web/cypress/e2e/recordings/01-onboarding-start-empty.cy.ts` | `just record-flow 01-onboarding-start-empty` |
| `02-budget` | Budget category group, category detail, and persisted category funding | `web/cypress/e2e/recordings/02-budget.cy.ts` | `just record-flow 02-budget` |
| `03-transactions` | Create, edit, and clear a categorized transaction | `web/cypress/e2e/recordings/03-transactions.cy.ts` | `just record-flow 03-transactions` |
| `04-account-transfer` | Paired investment contribution and resulting source/destination ledger state | `web/cypress/e2e/recordings/04-account-transfer.cy.ts` | `just record-flow 04-account-transfer` |
| `05-assets-liabilities` | Rich account list, account detail, and tangible-asset creation | `web/cypress/e2e/recordings/05-assets-liabilities.cy.ts` | `just record-flow 05-assets-liabilities` |
| `06-aspire-migration` | Dojo-owned deterministic Aspire fixture analysis, review, commit, and imported state | `web/cypress/e2e/recordings/06-aspire-migration.cy.ts` | `just record-flow 06-aspire-migration` |

Each recording includes asserted checkpoints. The MP4, checkpoint screenshots,
and review manifest are build artifacts and are intentionally not committed.
The final storyboard copies generated by `just storyboard` are the exception
because they provide a lightweight, repository-local visual overview.

The Aspire recording uses the existing `fixture` importer at the external
Google boundary. It does not contact Google and does not automate, mirror, or
fake Google's hosted consent UI. Real consent evidence belongs to the separate
human-browser procedure in `docs/google-oauth-verification.md`.
